# 🎓 Student Data Organizer
A simple **Python-based Student Data Organizer** that allows users to manage student information using a menu-driven program.

## 📖 Project Description

Student Data Organizer is a simple **Python-based project** designed to manage student information through a menu-driven program.

It allows users to **add, display, update, and delete student records**, as well as view the subjects offered by all students.

This project is created to practice Python programming concepts and data structures such as **lists, dictionaries, sets, and tuples**.

## ✨ Features

* ➕ Add Student
* 📋 Display All Students
* ✏️ Update Student Information
* 🗑️ Delete Student
* 📚 Display Subjects Offered
* 🚪 Exit the program
* 👤 Store student ID, name, age, grade, date of birth, and subjects
* 🔄 Update student name, age, grade, and subjects
* 🔢 Display subjects without duplicate values

## 🚀 How to Run / Installation

### 1️⃣ Install Python

Install **Python 3** on your computer.

### 2️⃣ Download or Clone the Project

Clone the repository using:

```bash
git clone <repository-url>
```

Or download the project as a ZIP file from GitHub.

### 3️⃣ 📂 Open the Project

Open the project folder in **VS Code**.

### 4️⃣ ▶️ Run the Program

Open the terminal in VS Code and run:

```bash
python main.py
```

The **Student Data Organizer** menu will appear in the terminal.
